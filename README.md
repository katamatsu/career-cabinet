# Career Cabinet

就活の企業情報、マイページのログイン情報、ES・面接メモ、添付資料を企業ごとに管理するブラウザアプリです。

## 現在の構成

- `index.html`：画面構造
- `style.css`：レスポンシブデザイン
- `app.js`：企業登録、検索、メモ、添付、JSON入出力
- 保存先：ブラウザの `localStorage`

## ローカルで確認する

`index.html` をブラウザで開いてください。ビルドツールは不要です。

## Vercel / Neon へ進む前に

現在のアプリはブラウザ内保存です。Vercel と Neon を使って複数端末から安全に利用するには、次の実装が必要です。

1. Vercel プロジェクトを GitHub リポジトリから作成
2. Neon で PostgreSQL データベースを作成
3. 認証用のサーバー/APIを追加
4. 企業情報、メモ、添付資料を Neon のテーブルへ移行
5. パスワードは平文で保存せず暗号化または秘密情報管理を導入
6. `DATABASE_URL` などの値を Vercel の環境変数に登録

> 注意：この現状版はブラウザの `localStorage` にログインIDとパスワードを保存します。共有端末では使用しないでください。Neon 公開版では認証と暗号化を追加してから利用してください。
